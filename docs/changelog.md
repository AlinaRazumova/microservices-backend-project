# Changelog

## Final MVP update

Implemented and documented the final MVP scope:

- completed Auth Service with registration, login, JWT and role management
- added automatic first-admin bootstrap
- completed Task Service CRUD operations
- added task filtering by status and priority
- added task search by title and description
- added task assignment support
- added Notification Service with basic notification list and read status
- connected Task Service with Notification Service for basic task events
- added PostgreSQL integration through SQLAlchemy
- added Docker Compose setup for all services
- added simple React client
- added Swagger/OpenAPI documentation for all backend services
- updated README and documentation
- added CI workflow for basic validation
